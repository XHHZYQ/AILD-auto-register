# AILD Auto Register

Chrome MV3 自动报名插件。

## 当前进度

- 已创建可加载的 Chrome 扩展骨架。
- 已接入 `asset/icon.png` 作为插件图标。
- 弹窗已包含执行前设置：从 Excel 第几行开始、完成几个学生后暂停、开始、暂停、继续执行、当前学生和状态显示。
- 内容脚本已具备基础页面连通检测，会等待 `.form-container` 且文本包含 `参赛信息` 后再进入后续流程。
- 已接入本地 SheetJS，读取插件内置的三份 Excel。
- 已实现 Excel 表头“包含匹配”，并自动选择最符合字段要求的 sheet。
- 已标准化学生、内部指导老师、外部指导老师数据，可按学生行号匹配指导老师。
- 已实现年级到队员组别映射，以及北京、天津、上海、重庆直辖市省市标准化。
- 已实现快捷指导老师区域检测：等待 `.form-container .teacherICon` 渲染，按老师姓名包含匹配，命中后自动点击并跳过指导老师表单。
- 已实现指导老师表单填写：快捷老师区没有当前老师时，从内部/外部老师表读取姓名、性别、民族、证件、手机、邮箱、学校/单位并填写。
- 已解析 Excel 内嵌 `DISPIMG` 图片资源，并在上传控件中注入图片文件，等待 `.el-upload img[src]` 渲染后再继续。
- 指导老师证件类型保持页面默认身份证号，不主动选择；资格证书为空时跳过上传。
- 已实现参赛信息填写：项目名称固定选择“智能算法编程”，场景名称固定选择“智械未来”，队员组别按学生年级映射。
- 已实现省市选择，直辖市市级选项优先匹配“北京/上海/天津/重庆”，再兼容“北京市/市辖区”等页面选项。
- 已实现团队名称生成和重复处理：名称限制为 5 个汉字以内，失焦后如出现重复弹窗则确认关闭并换名重试。
- 已实现“添加队员”弹窗填写：点击添加队员，填写学生姓名、性别、民族、学校、年级、身份证号、监护人邮箱、监护人手机，上传学生照片后提交并等待弹窗关闭。
- 已开始按功能模块化拆分：`lib/excel-data.js` 负责 Excel 数据读取，`lib/register-actions.js` 负责预览确认、提交报名、成功弹窗和返回主页面。
- 已实现预览确认和提交报名：点击“预览确认”，等待“初赛报名表”渲染，点击“提交报名”，处理“报名成功”弹窗并返回报名主页面。
- 已实现承诺书弹窗处理：勾选“我已阅读，继续报名”，点击“确认”，等待弹窗关闭。
- 已实现多学生循环：单个学生完整提交后进入下一行；每次执行完成设置数量后自动暂停，继续执行会从下一 Excel 行继续。

## 加载方式

1. 打开 Chrome 扩展管理页：`chrome://extensions/`。
2. 开启开发者模式。
3. 选择“加载已解压的扩展程序”。
4. 选择本项目下的 `extension` 目录。
